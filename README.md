# Floyd-Steinberg-Dithering
boot.dev personal project

## What it is
A python cli program that reduces the number of colors in an input image and dithers it using the Floyd-Steinberg algorithm (because I think it is neat).

## How it works (aka `usage: `)
Either call `main.py` with the python interpreter or use `main.sh` if you use Linux.  
The parameters are as follows:  

`python3 main.py <path/to/image.png> <number of colors to reduce to> <path/to/output.png>`  

Currently, only png is supported.
